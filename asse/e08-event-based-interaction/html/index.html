When Does an Instance Count?

Rule 4: an instance counts exactly when

  • (a) the decision log lists it
  • (b) every group VM reaches it at its public hostname or address, not at a private one
  • (c) at least one group other than its operator uses it in a demonstration
  • (d) if a group operates it, it runs on that group's VM or an extra VM from the course

Demonstrator Instances

Rule 5: an instance that does not count may still serve as a demonstrator

  • Show it to the task force to back your arguments, e.g. that an alternative works
  • Using it as a demonstrator does not make it count (Rule 4)
